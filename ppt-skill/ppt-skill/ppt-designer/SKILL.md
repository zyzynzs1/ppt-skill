# PPT 设计生成技能

## 一、何时使用本技能

当用户提到「ppt」「幻灯片」「汇报」「路演」「slides」等关键词，或明确要求制作/美化/生成任何主题的演示文稿时，启用本技能。本技能产出的风格定位：**结构化信息图风格的技术商务汇报**——高密度内容、卡片化布局、统一的视觉语言，适合方案汇报、产品介绍、投标响应、培训材料、咨询报告。

## 二、工作流程（必须严格按顺序执行）

### 第一阶段：需求确认（访谈）
在生成任何页面之前，必须先向用户提问以填补空白，**切勿假设上下文**。至少确认：

1. **主题与目的**：汇报对象是谁（管理层/客户/评委/学员）？期望对方听完后记住什么、采取什么行动？
2. **场合与时长**：演讲时长决定页数（经验值：每分钟 1~1.5 页，技术汇报约 20~30 页）。
3. **内容来源**：由用户直接提供文案/资料？还是由技能方根据大纲代拟内容？（代拟内容须标注【待确认】）
4. **硬性约束**：品牌主色/Logo/必须出现的页面（如资质证书、团队介绍）、交付格式（.pptx 源文件/PDF）、截止时间。
5. **页数与章节**：如用户无明确想法，按第三节结构规范给出章节划分建议并确认。

### 第二阶段：策划大纲与页面规划
1. 用「总—分—总」搭建章节骨架：封面 → 目录 → 3~6 个章节（每章 2~8 页）→ 总结/致谢。
2. 为每一页写**结论式标题**（判断句或短语，一眼看出本页观点，禁止"介绍""概述"类空标题），并标注该页拟使用的页面原型（见【五、页面原型】）与组件类型。
3. 将页面规划表与用户确认后，方可进入第三阶段。页面规划表格式：

| 页码 | 章节 | 结论式标题 | 页面原型 | 核心组件 |
|---|---|---|---|---|
| 03 | 01 项目理解 | 免切图流程从源头消除分发差错 | 三列卡片 | 编号徽章+对比表 |

### 第三阶段：生成文件
按【三、设计系统】与【四、组件规范】执行设计；用 python-pptx 生成（可参考 `scripts/pptx_helpers.py` 中的现成函数）。生成后执行【七、质量检查清单】自查，并**将成品逐页导出为图片自检**（排版溢出、对齐漂移、色块错位必须修复后交付）。

## 三、设计系统（Design Tokens）

> 全部令牌见 `templates/design-tokens.md`，此处为强制摘要。

### 1. 画布与栅格
- 画布：16:9，10in × 5.625in（即 25.4cm × 14.29cm）
- 页边距：左右 0.5in，上 0.3in，下 0.2in；内容区 y 范围 0.85 ~ 5.3in
- 页脚基线：y=5.44in，左侧文档名，右侧页码，9pt
- 版面节奏：内容页优先 2~4 列网格；卡片间距 ≥0.15in；同类卡片严格等宽等高、顶边对齐

### 2. 配色（蓝金双色系统）
| 角色 | 色值 | 用途 |
|---|---|---|
| 深藏蓝 INK | #12263F | 正文标题、深色底块、封面主色 |
| 深蓝 NAVY | #0F2B52 | 页标题文字、深色卡片 |
| 主蓝 PRIMARY | #0068B7 | 标题侧装饰条、编号、强调、图标 |
| 钢蓝 STEEL | #4A6B99 | 次级标题、图表主系列 |
| 浅蓝阶梯 MIST→CLOUD | #9FB8D8 / #D5E3F0 / #E3F0FB / #EFF5FB / #F4F9FF | 分隔线、卡片描边/底色、页面背景（整页铺 #EFF5FB 淡蓝底，非纯白） |
| 强调金 GOLD | #C9983B（深 #8A5B14 / 浅 #EAD3AE / 底 #FDF9F0） | 每页至多 1~2 处点睛：关键数字、核心结论、亮点徽章 |
| 青 CYAN | #37B6E6 | 封面/科技感点缀，正文慎用 |
| 正文 TEXT | #12263F（85% 黑可接受） | 正文与说明文字 |

配色纪律：单页色相 ≤3 种（蓝系算一种）；金色为强调色，面积不超过页面 5%；严禁出现红绿撞色、彩虹渐变。

### 3. 字体与字号（全稿仅允许一种中文字体）
- 中文：微软雅黑（Microsoft YaHei）；西文/数字：同用微软雅黑或 Arial；**禁止混用第二种中文字体**
- 字号阶梯（pt）：封面主标题 32 / 页标题 16-18 / 卡片标题 12 / 正文 9-10 / 辅助说明与英文小字 7.5-8 / 页脚 9
- 行距：正文 1.15~1.3 倍；英文装饰性全大写小字（如 `WHOLE-SHEET SCANNING`）字距加宽，仅作卡片副题

### 4. 页面骨架（所有内容页统一）
1. 整页底色矩形 #EFF5FB
2. 左上标题组：主蓝短竖条（宽约 0.06in，高约 0.27in）+ 页标题（NAVY，16-18pt 加粗），标题下可接一行 9pt 导语
3. 内容区：按页面原型排布组件
4. 页脚：左侧「文档主题 · 文档类型」9pt 灰蓝，右侧页码两位数字（如 03）

## 四、组件规范

> 详细参数见 `templates/design-tokens.md` 组件表，常用组件如下。

1. **编号徽章**：圆形或圆角方块内放两位数字（01/02…），主蓝底白字或蓝框白底，用于卡片、流程步骤、目录条目的序号。同级徽章样式必须一致。
2. **信息卡片**：圆角矩形（roundRect），白底或 #F4F9FF 底，1pt #D5E3F0 描边（可省）；自上而下为：图标/徽章 → 12pt 标题 → 7.5pt 英文副题（可省）→ 9pt 要点列表（• 开头，每点一行，单行不超 22 字）。
3. **对比表**：两列对比用「标签列 + 内容列」结构；本方方案列用浅蓝底 #F4F9FF，对照列白底；结论行用金底 #FDF9F0 点睛。
4. **流程/管道**：横向或纵向步骤链，节点用编号徽章+短标题+一行说明，节点间用箭头连接（直线 connector，主蓝或钢蓝）；阶段多时先分「阶段带」（深蓝底白字阶段名），再在带内排步骤。
5. **架构/拓扑图**：分域框（深蓝标题条 + 白底内容区），域内设备/模块用白底小卡片，域间用箭头标注数据流向；整体图必须外网无关元素零出现，图例简洁。
6. **数据指标块**：大数字（28-36pt 主蓝或金色）+ 单位 + 8pt 说明文字，3~4 个为一组横排，用于性能、规模、成果页。
7. **金句/结论条**：页面底部或右侧放置通栏浅金底 #FDF9F0 圆角条，内放加粗结论一句，前缀可用 ▎竖条装饰。
8. **截图位**：软件界面截图统一加 1pt 描边 + 浅阴影，下方 8pt 灰字图注「系统界面 · xxx（截图位）」，等宽排列。

组件纪律：同页同类组件宽度、圆角、配色完全一致；箭头只用直角或直线，不用曲线；装饰元素（圆点、斜切色块）不得干扰阅读区。

## 五、页面原型（Archetypes）

> 完整版式坐标与绘制步骤见 `templates/page-archetypes.md`。

| 原型 | 用途 | 要点 |
|---|---|---|
| A 封面 | 全稿第一页 | 深藏蓝大色块+几何装饰（矩形/圆形切片，主蓝/青/金点缀）；左上 10pt 英文小字（TOPIC · TECHNICAL PROPOSAL）；32pt 主标题两行；一句 12pt 副标题点明模式/价值；底部汇报人与年份 |
| B 目录 | 章节导航 | 左侧大号「目录 CONTENTS」竖排区（占宽 1/3）；右侧章节条目列表：编号徽章+章节名 12pt+要点 8pt+页码右对齐 |
| C 标准内容页 | 全稿 80% 页面 | 第四节页面骨架 + 任选组件组合；一页只讲一个观点，信息分 2~4 个卡片区块 |
| D 章节过渡页 | 大章节切换（可选） | 深蓝整底+超大章节号+章节名，与封面呼应 |
| E 数据/成果页 | 指标与统计 | 顶部大数字指标组，下方图表或分析卡片 |
| F 结尾页 | 致谢 | 深藏蓝整底，中央「谢」字/THANKS + 一句收尾语 + 文档主题落款 |

## 六、内容写作规范

1. **标题即结论**：每页标题是一句可独立成立的判断（如「免切图分发从源头消除错位风险」），禁止「XXX介绍」「XXX说明」。
2. **要点句式**：卡片内用 `• 动词开头短语`，一行一条，宁可拆页不放小字；每条 ≤22 字（中文），超出即精简或拆分。
3. **数字必量化**：性能、规模、时间等尽量给具体数字；不确定的信息标注【待确认】，严禁编造数据、资质、证书编号。
4. **中英配比**：英文仅用于封面小字、卡片副题、图注中的术语，正文一律中文。
5. **术语一致**：同一对象全稿称谓统一（如选定「全卷影像」后不得再写「整卷图像」混用，除非语义不同）。
6. **密度控制**：单页正文要点 ≤12 条；超过则拆页或用「总览页+详情页」两级展开。

## 七、质量检查清单（交付前逐项自查）

- [ ] 画布 16:9，全部页面统一页脚（文档名 + 两位页码）
- [ ] 每页标题为结论式判断句，且标题组含主蓝装饰条
- [ ] 全稿仅一种中文字体（微软雅黑），字号符合阶梯
- [ ] 页面底色 #EFF5FB，单页色相 ≤3，金色强调 ≤2 处/页
- [ ] 同类卡片等宽等高、间距一致、顶边对齐；文本零溢出、零遮挡
- [ ] 编号徽章、箭头、对比表、指标块样式全稿一致
- [ ] 所有截图带描边与图注；所有【待确认】项已与用户对齐
- [ ] 无编造数据/资质；术语全稿统一
- [ ] 逐页导出图片人工巡检通过（对齐、配色、溢出）
- [ ] 文件可正常打开，字体无缺失替换告警
