# 设计令牌（Design Tokens）

> 本文件是 ppt-designer 技能的参数总表。生成 PPT 时所有颜色、字号、间距一律取自本表，禁止临时发明新值。

## 1. 画布与栅格

| 令牌 | 值 |
|---|---|
| 页面尺寸 | 16:9，10in × 5.625in（EMU: 9144000 × 5143500） |
| 左右边距 | 0.5in（457200 EMU） |
| 上边距 | 0.3in；标题区高 0.55in |
| 内容区 | y: 0.85in ~ 5.3in，可用宽 9.0in |
| 页脚基线 | y = 5.44in，高 0.15in |
| 卡片间距 | ≥ 0.15in；列间距统一 0.18in |
| 卡片内边距 | 0.12in（文字距卡片边缘） |
| 圆角 | 卡片 roundRect 默认圆角半径 0.06~0.1in；徽章用椭圆或 0.08in 圆角 |

## 2. 配色

| PRIMARY | #0068B7 | 标题装饰条、编号徽章、强调词、箭头、图标 |
| STEEL | #4A6B99 | 次级标题、图表主系列、表格表头底 |
| MIST | #9FB8D8 | 弱化图标、次级描边 |

| CARD | #F4F9FF | 卡片底（比 BG 更浅的近似白） |

### 金系（强调色家族，全页面积 ≤5%）
| 令牌 | HEX | 用途 |
|---|---|---|
| GOLD | #C9983B | 关键数字、核心结论、亮点徽章 |
| GOLD_DK | #8A5B14 | 金底上的文字 |
| GOLD_LT | #EAD3AE | 金色装饰线、浅点缀 |
| GOLD_BG | #FDF9F0 | 结论条/重点行底色 |

### 功能色
| 令牌 | HEX | 用途 |
|---|---|---|
| CYAN | #37B6E6 | 封面科技感点缀、装饰图形 |
| WHITE | #FFFFFF | 卡片底、深色块上的文字 |

### 禁用
- 红 #FF0000、绿 #00FF00 等正色；彩虹/多色渐变；灰色系正文（正文用 INK 不用纯黑 #000000 以外的灰）

## 3. 字体与字号

- 全稿唯一中文字体：**微软雅黑**；西文数字：Arial 或微软雅黑，全稿统一
- 禁止：斜体中文、艺术字、描边字、阴影堆叠

| 令牌 | 字号 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| COVER_TITLE | 32pt | Bold | WHITE/NAVY | 封面主标题（最多两行） |
| COVER_SUB | 12pt | Regular | WHITE/GOLD | 封面副标题一句 |
| COVER_KICKER | 10pt | Regular | GOLD_LT/CYAN | 封面顶部英文小字（字距宽） |
| PAGE_TITLE | 16-18pt | Bold | NAVY | 页标题（结论式） |
| LEAD | 9pt | Regular | INK 80% | 标题下导语一行 |
| CARD_TITLE | 12pt | Bold | NAVY/INK | 卡片/区块标题 |
| CARD_EN | 7.5-8pt | Regular | STEEL | 卡片英文副题（全大写、加字距） |
| BODY | 9-10pt | Regular | INK | 正文要点 |
| SMALL | 8pt | Regular | STEEL | 图注、来源、辅助说明 |
| FOOTER | 9pt | Regular | STEEL | 页脚文档名与页码 |
| KPI_NUM | 28-36pt | Bold | PRIMARY/GOLD | 数据指标大数字 |

- 行距：BODY 1.15~1.3；段后距 2-4pt
- 要点符号：`• ` + 空格，悬挂缩进与文本对齐

## 4. 页面骨架（内容页，逐页必做）

```
[0] 整页矩形 BG#EFF5FB（0,0,10,5.625）
[1] 标题装饰条 PRIMARY 矩形 (0.375, 0.344, 0.0625, 0.266)  # 竖条
[2] 页标题文本   (0.523, 0.30, ~5, 0.34)  16-18pt Bold NAVY
[3] 导语（可选） (0.54, 0.85, 9.0, 0.18)  9pt
[4] 内容区组件（见第 5 节）
[5] 页脚左       (0.48, 5.44)  9pt STEEL 「主题 · 文档类型」
[6] 页脚右       (9.16, 5.44)  9pt STEEL 两位页码 01/02/…
```

## 5. 组件参数表

### 5.1 编号徽章
- 形状：椭圆或 0.08in 圆角方块，直径/边长 0.28~0.4in
- 样式 A：PRIMARY 底 + WHITE 数字 10-12pt Bold
- 样式 B：白底 + PRIMARY 1.5pt 描边 + PRIMARY 数字
- 同级同页只能选一种样式

### 5.2 信息卡片
- roundRect 圆角 0.08in；底 CARD #F4F9FF 或 WHITE；描边 LINE 1pt（可省）
- 内部自上而下：徽章/图标 → CARD_TITLE → CARD_EN（可省）→ BODY 要点列表
- 三列标准布局：单卡宽 = (9.0 − 2×0.18)/3 ≈ 2.88in；卡高按内容统一，同排必须等高

### 5.3 对比表
- 结构：标签列（0.9in，TINT 底，9pt Bold）+ 各方案列（等宽）
- 本方列 CARD 底，对照列 WHITE 底；行间 0.5pt LINE 分隔
- 结论/优势行：GOLD_BG 底 + GOLD_DK 文字

### 5.4 流程链
- 节点：徽章（数字）+ 短标题 10pt Bold + 说明 8pt（≤2 行）
- 连线：直线 connector，PRIMARY/STEEL 1.5pt，末端箭头
- 多阶段：先铺 NAVY 阶段带（高 0.3in，WHITE 10pt Bold 阶段名），带内并排步骤
- 步骤数 >6 时纵向排列或拆为两条链，禁止一横排挤 7 个以上节点

### 5.5 架构/拓扑图
- 分域框：NAVY 标题条（高 0.3in）+ WHITE 内容区，域间距 0.25in
- 域内元素：WHITE 小卡 + LINE 描边，9pt 名称 + 8pt 说明
- 域间连线：带箭头，旁注 8pt 说明数据流向

### 5.6 数据指标块
- 横排 3~4 个：KPI_NUM（PRIMARY 或 GOLD）+ 单位 12pt + 说明 8pt 两行内
- 下方可接来源或口径 SMALL 字

### 5.7 结论条
- 通栏 roundRect GOLD_BG 底，高 0.35in
- 前缀 ▎GOLD 竖条装饰，文字 GOLD_DK/INK 10pt Bold，一句话

### 5.8 截图位
- 截图等比缩放，最大宽不超过内容区 80%；1pt LINE 描边
- 图注：SMALL「系统界面 · 名称（截图位）」居中或左对齐

## 6. 图表规范（如使用原生图表）

- 图表主系列 PRIMARY，次系列 STEEL，强调系列 GOLD；背景 WHITE 或透明
- 去掉默认网格线（或改 LINE 色 0.5pt），坐标轴标签 8pt STEEL
- 图例置底部或右侧，8pt；数据标签仅在关键处标注
