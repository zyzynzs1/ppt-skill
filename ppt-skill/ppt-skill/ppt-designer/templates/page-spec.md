# 页面规格卡（Page Spec）

> Stage 2 逐页填写。这是内容深度的抓手：**先填卡、后画图**。卡片没填完不得进入 Stage 3。
> 思想来源：每页先回答"这一页必须为读者做什么"（页面任务），再决定放什么内容、用什么版式。版式服务于任务，不是装饰。

## 1. 空卡模板

```markdown
### 第 NN 页 · {页面任务一句话}

| 字段 | 填写内容 |
|---|---|
| 页面任务 | 本页必须为读者做的唯一一件事（动词开头，如"让评委相信系统性能达标"） |
| 章节 | 0X 章节名 |
| 观点（页标题） | 结论式判断句 |
| 支撑证据 | L1 机制：___ / L2 参数：___ / L3 数据：___（每层能填则填，填不了写"无→用下层补"） |
| 内容维度 | D?（D1-D9，可多选） |
| 原型 | C1/C2/C3/C4/C5/E（见 page-archetypes.md） |
| 组件 | 编号徽章/卡片/对比表/流程链/规则表/截图位… |
| 素材 | 已有素材 或 【待确认：xxx】 或 images/{页码}-{语义}.png |
```

## 3. 深浅对比（自检标尺）

**❌ 浅（不合格，C2/C3 会拦下）**

> 观点：我们有多评机制保证公平
> 支撑：采用双人背靠背评卷，误差大时由组长处理，确保质量。（无参数、无角色、无数据）

**✅ 深（合格）**

> 观点：三级误差阈值分流，零分三策略兜底
> 支撑：双评差值≤正常阈限直接取均值出分；≥异常阈限自动转小组长仲裁，仲裁可见前两评；≥审核阈限转专家组。零分卷按题目预设走"禁用/标准处理/提交审核"三策略之一，避免 0.5 分争议。（机制+参数+角色齐全）

## 4. 填写纪律

1. **页面任务先于版式**：先写任务，再选原型；任务说不清就并页或拆页
2. **L2 是硬门槛**：每张卡至少有一层写到参数；全稿 L2 ≥5 处
3. **素材三态**：已有 / 【待确认：具体问题】 / 占位+告知补图，禁止第四种"假装有"
4. **规格卡与图一一对应**：Stage 4 质检时逐页对照，图与卡不符以卡为准返工
