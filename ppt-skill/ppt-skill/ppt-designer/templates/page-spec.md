# 页面名册卡（Page Roster）v2

&gt; Stage 2 逐页填写。**先填卡、后画图**；卡不填满不得进入 Stage 3。
&gt; v2 核心变化：从"关键词骨架"升级为"完整可用文案"。**完整内容字段必须写成句、带限定词、带论据**，这是内容深度的载体；视觉字段（原型/组件）排在最后，服务而非主导内容。

## 1. 空卡模板（七字段缺一不可）

```markdown
### 第 NN 页

| 字段 | 填写内容 |
|---|---|
| ① 页面任务 | 本页必须为读者做的一件事（动词开头，如"让评委相信系统性能达标"） |
| ② 观众动作 | 读完本页观众应得出的判断/立场（如"认可双模式架构是行业主流方案"）——论证齿轮，缺了页面就是孤岛 |
| ③ 观点（页标题） | 结论式判断句 |
| ④ 语义关系 | order / link / parent / membership / contrast / overlap / none（本页内容单元之间的关系） |
| ⑤ 完整内容 | ⭐ 完整成句的可用文案：所有论点、事实、限定词都在；每个核心论点带参数/证据。宁拆页不删减 |
| ⑥ 事实来源 | F 编号清单；无来源写【假设】 |
| ⑦ 原型+组件 | C1/C2/C3/C4/C5/E + 组件（Stage 3 才填也允许） |
```

## 2. 语义关系 → 表达形式对照（填④⑤时对照使用）

| 关系 | 含义 | ⑤ 的表达形式 |
|---|---|---|
| order | 流程、时序、步骤 | 编号步骤链或"先…再…最后…"完整句 |
| link | 因果、依赖、条件 | 完整句保留连接词："因为…所以…""当…时…""只有…才…" |
| parent | 总分、包含、上下位 | 总起句+分述句，或父卡+子卡 |
| membership | 并列成员、可枚举清单 | 唯一允许 `•` 列表的场景 |
| contrast | 对比、差异 | 对比表，或"相比之下…"成句 |
| overlap | 交叉、重叠 | 重叠句说明共有部分 |
| none | 单点陈述 | 一段完整陈述句 |

**禁止**：把 link（因果）内容写成 membership（并列列表）——这是内容变浅的典型事故。

## 3. 深浅对照示例（同一主题，填卡质量的天壤之别）

### ❌ 浅（v1 骨架式写法，C2/C3 必拦）

&gt; ③ 观点：系统有多重安全保障
&gt; ④ 关系：membership
&gt; ⑤ 完整内容：数据加密、霸屏模式、人脸识别、内容乱序、异常续考、轨迹记录

### ✅ 深（v2 完整式写法）

&gt; ③ 观点：六道防线覆盖"考前泄题、考中舞弊、考中异常"三类风险
&gt; ④ 关系：parent（三类风险 → 六道防线，其中数据加密/霸屏/人脸/乱序归防舞弊类）
&gt; ⑤ 完整内容：
&gt; **防泄题**：试卷包采用国密算法非对称加密+分片加密碎片化传输，密钥文件匹配才能解密，从机制上杜绝考前获取试题的可能。
&gt; **防舞弊**：四道并行防线——①霸屏模式禁止切出作答界面，阻断场外检索；②人脸识别比对考生面部特征，防替考代考；③试题+选项双乱序，使每名考生作答内容不同；④全部作答轨迹实时记录，考后可逐秒复盘。
&gt; **防异常**：断网/设备故障时支持换机位、换考场、换场次继续作答，作答数据本地缓存+恢复后自动续传，确保任何异常都不导致考生弃考。
&gt; ⑥ 事实来源：F012（国密加密）、F014（双乱序）、F016-F018（异常续考）
&gt; ⑦ 原型：C4 三域分栏；组件：分域框×3

## 4. 填写纪律

1. **⑤ 写给人读的句子，不是给搜索用的关键词**——检验法：把⑤直接念出来，不通顺即不合格
2. **每个核心论点必须带参数或证据**：机制+数字/规则/阈值，"有误差控制"不合格，"双评差值≤2分取均值、超差转仲裁"合格
3. **拆页优先于删减**：一页装不下就拆成"总览页+详情页"，⑤ 的内容总量不减
4. **图卡一致性**：Stage 4 质检逐页对照，图上文字少于⑤即返工
5. **六要素可两行**：完整句允许占两行，不受旧版"≤22字"约束
