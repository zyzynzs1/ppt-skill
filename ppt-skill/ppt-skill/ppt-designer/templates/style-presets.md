# 风格预设（Style Presets）

&gt; Stage 1 做风格判断，Stage 3 前读匹配预设的本文件。**预设制：四选一或品牌 VI，禁止混搭、禁止自定义第五套。**
&gt; 每套预设只规定与默认（预设 A）有差异的部分，未提及的纪律（栅格/字号阶梯/组件规则/质检）全部沿用 design-tokens.md。

## 预设 A · 藏蓝政务商务（默认）

**信号**：政务/考试院/国企汇报、投标响应、建设方案。
**与默认令牌关系**：即 design-tokens.md 默认蓝金全套，无差异。
**封面规范**：深藏蓝整底 + 右侧几何色块（主蓝/青/金），左文右饰。
**配图基调**：截图/架构图为主，照片类配图慎用，不用插画。
**禁忌**：不用深色渐变全屏背景、不用荧光色、不用圆角过大的可爱化卡片。

## 预设 B · 科技深色

**信号**：产品发布、技术大会、互联网产品、开发者场景。
**配色**（整组替换）：
- 底色 BG `#0E1420`；卡片底 CARD `#182234`；深块 INK `#05090F`
- 主色 PRIMARY `#3D7FFF`；强调 CYAN `#39D0D8`；点缀 PURPLE `#7B61FF`（面积 ≤5%）
- 正文 `#E8EEF7`；辅助 `#8FA3C0`；分隔 `#26334A`
- 金色禁用（科技感场景金色显脏）
**字体纪律**：标题可加大字距；数字可用等宽风格（Consolas/Arial）强化"数据感"。
**封面规范**：深色全底 + 大幅产品界面截图或抽象光效图形 + 发光色条点缀。
**配图基调**：产品截图优先，可配深色科技感底图；截图加微发光描边（主色 1pt）。
**组件差异**：卡片可用直角或小圆角（0.03in）；结论条改为左侧色条发光样式。
**禁忌**：禁大面积纯白卡片破坏暗色氛围；正文字号不得小于 9pt（暗底更小看不清）。

## 预设 C · 清新教育

**信号**：教育培训、校园场景、课程教材、师资培训。
**配色**（整组替换）：
- 底色 BG `#FAF8F3`（暖白）；卡片底 `#FFFFFF`；分隔 LINE `#E8E2D5`
- 主色 PRIMARY `#2E8B6E`（教育绿）；次色 TEAL `#4FA3A5`；点缀 GOLD `#E0A93E`（面积 ≤5%）
- 标题 `#1E3A2F`；正文 `#2B2B2B`；辅助 `#7A7A6A`
**字体纪律**：标题可用更圆润字重；正文维持 9pt 保证可读性。
**封面规范**：暖白底 + 顶部或侧部插画/校园场景图 + 主色圆角色块；整体留白 ≥40%。
**配图基调**：插画、场景照片、学员操作照片优先；截图可配圆角卡片容器。
**组件差异**：圆角加大至 0.12in；徽章可用方形圆角；多用图标+短句的轻卡片。
**禁忌**：不用深色整底（压迫感）、不用金属渐变、单页信息密度不超过 A 预设的 80%。

## 预设 D · 极简咨询

**信号**：咨询报告、商业计划、路演融资、市场分析。
**配色**（整组替换）：
- 底色 BG `#FFFFFF`（纯白）；卡片底 `#FFFFFF`；分隔 LINE `#E5E5E5`
- 标题文字 INK `#111111`；正文 `#333333`；辅助 `#888888`
- 唯一强调色 ACCENT `#D64045`（咨询红，面积 ≤8%）；图表次系列 `#9AA5B1`
- 蓝金默认色禁用
**字体纪律**：全稿仅黑白灰+单一强调色；标题加粗、正文常规，通过字重与字号建立层级，不依赖色块。
**封面规范**：纯白底 + 超大标题左对齐 + 底部一条强调色细线；可配单张高质感大图（右侧 40%）。
**配图基调**：高质量照片大图（全幅出血）、极简图表；截图需配浅色描边与说明文字。
**组件差异**：卡片去底色去描边，用留白分组；结论条改为强调色左边线 + 白底；KPI 数字超大号。
**禁忌**：禁渐变、禁阴影堆叠、单页颜色除黑白灰与强调色外不得出现第四种。

## 风格判断速查（Stage 1 使用）

```
材料含"方案/响应/建设/考试院/政务/招标"      → A
材料含"发布会/产品/大会/全新上线/用户体验"    → B
材料含"课程/教学/学员/校园/师资/教材"        → C
材料含"市场/财务/ROI/融资/战略/咨询"         → D
多信号冲突或全无信号                        → 问用户（Hard rule）
```
